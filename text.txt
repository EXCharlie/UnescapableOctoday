艺术网页，用于展示微视频制作。
禁止ai味网页。
代码简洁清晰，结构清晰，定义规范。
全部使用系统字体。

逻辑：全屏黑色背景，加载当前文件夹的demo.mp4并且全屏播放，填充满屏，不能拉伸。从头自动播放，隐藏任何播放控件。
播放结束后视频立即停止并且消失，然后在画面中间的右侧，也就是文本和播放组件都是左对齐。依次插入大字号标题Unescapable（极细） Octoday（加粗）、简介（稍微灰色一点的白色的小字号），播放控件（胶囊型，播放三角形+Play）、以及向下滑动继续的提示（用english）。
鼠标继续向下滚动，整个头部组件向左滑动，然后Cast & Crew（极细字体）组件从右边滑动进来（并且滚动到中间的时候要有白色外围发光效果），然后一开始演员表的内容是透明不可见的，在该组件在屏幕中间65%的部分是透明度为0，超出中心75%透明度100.
然后依次类推。一直到图片为止。
这些部分均限制一个高度，占用屏幕一般的高度差不多。
一定要体现设计美感，可以适当加一些提高交互体验到动效。

Art portfolio webpage for showcasing a micro-video production.
No AI-generic webpage aesthetic. Keep code concise, well-structured, with standardized definitions. Use only system fonts.

Logic:
Full-screen black background. Load demo.mp4 from the current folder and play fullscreen. Scale the video to fill the viewport without stretching. Auto-play from the start, hide all media controls.

Once playback finishes: the video stops immediately and disappears. Then render content to the right of the screen center. All text and player components are left-aligned.
Render elements in sequence:
1. Large heading: "Unescapable" (ultra-thin font weight), "Octoday" (bold)
2. Synopsis text: small text, off-white with slight gray tint
3. Capsule-shaped play button: play triangle icon + text "Play"
4. Scroll prompt in English, instructing users to scroll down to continue

On mouse scroll down:
The entire header component slides to the left.
The "Cast & Crew" section (ultra-thin font) slides in from the right. When this component reaches the vertical middle of the viewport, add a soft white outer glow effect.
The cast list starts fully transparent. Its opacity follows this rule: opacity = 0 when the component is within the central 65% viewport area; opacity = 100% when outside the central 75% viewport range.

This pattern continues for subsequent sections until the image section.
Each of these sections is constrained to roughly half the viewport height.

Focus on refined visual design. Add subtle animations to enhance user interaction experience.

时间：2025.3.2-3.9
地点：主教学楼 高二8班（2026届）
课堂上，一个小小的灵感突然冒了出来 —— 时间囚笼。我当时就觉得这个设定很有意思，一直想召集同学们一起拍一部短片，而影视创作也是我从未接触过的全新领域。和几位同学讨论过后，大家都觉得这个故事值得尝试。整个团队格外齐心：有创意的同学贡献想法，愿意参演的人牺牲周末时间参与拍摄，物理老师也友情客串，众人合力，才有了最终的成片。
《无法逃离的星期八》原本是学校科学文化艺术节的参赛作品。似乎没人料到高二 8 班能完成这样体量的短片。作品完成后，被校方以影响不好曾被临时下架。当年本届科艺节最终也没有开展评奖。
